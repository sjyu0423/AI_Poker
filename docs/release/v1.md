# PokerMind v1: release readiness

**Status:**
* **Ready for a portfolio release** as a local-first application.
* **Research:** frozen at configuration v1.0.0, digest `a67a2826…`.
* **Platform:** verified on macOS (Apple silicon), Python 3.12.16 and
  Node.js 26.

## Features in v1

* **Play.** Heads-up Leduc Hold'em in the browser against PokerMind.
  * Server-enforced rules, seats that alternate, settlement on the server.
  * The AI's card is hidden until a showdown.
  * Keyboard shortcuts; desktop, tablet and phone layouts.
* **Adaptive AI.**
  * Starts from a CFR equilibrium baseline (certified exploitability
    0.0030 chips/hand).
  * Models the player with a Bayesian model and change detection.
  * Re-solves with Restricted Nash Response in a background process.
  * Installs a new strategy only after exact re-certification within
    0.1030 chips/hand.
* **Learning dashboard.** It shows:
  * observed counts;
  * estimated tendencies, with 90 % intervals, the typical-player prior,
    sparse-data warnings, and a disclaimer that they are not validated for
    humans;
  * certified strategy versions with their exploitability;
  * plain-language explanations tagged observed, estimate, certified or
    status.
* **One-command launch.** `pokermind launch`:
  * checks the setup;
  * builds the web app when needed;
  * supervises both services and stops them cleanly;
  * `--demo` paces updates for recordings.
* **Reproducible research.** Experiments M0–M7B are seeded, documented, and
  regenerable with the commands in each results document.

## Install and launch

See the README's [Quick start](../../README.md#quick-start-macos). In short:

```bash
python3.12 -m venv .venv && .venv/bin/pip install -e ".[app]"
(cd web && npm ci)
.venv/bin/pokermind launch --train-hero    # once, ~30 min (the hero file is not in git)
.venv/bin/pokermind launch                 # http://localhost:3000, Ctrl-C to stop
```

## Fresh-install test

Two clean environments, separate from the development checkout:

1. **Clone from GitHub, then train the hero.** Steps: clone the M8C branch,
   create a new Python 3.12 venv, `pip install -e ".[app]"`, then run the
   documented `train-cfr` command (the one `pokermind launch --train-hero`
   runs). Results:
   * training took 1,857 s;
   * exploitability 0.002997;
   * strategy digest **`3f1136d4…`, identical to the frozen configuration's**.

   The hero is reproducible bit for bit from a fresh clone on this platform.
2. **A clean copy of exactly the files of this release.** It has no `runs/`,
   no `.venv/` and no build. Steps: a new venv with `pip install -e ".[app]"`
   (7 s), then `npm ci`. Results:
   * without a hero, `pokermind launch` stops with the exact training
     command;
   * with the hero trained in step 1, `pokermind launch --api-port 8100
     --web-port 3100`:
     * built the web app;
     * started both services;
     * served the page;
     * played 5 hands through the web proxy, with certified strategy v1;
     * stopped cleanly on Ctrl-C (exit 0, no processes left).

All numbers come from simulated opponents, except the exact guarantees.

| result | value | type |
|---|---|---|
| Exploitability of the CFR hero (Leduc, 100k iterations) | 0.0030 chips/hand | exact |
| Exploitability limit of every strategy played | 0.1030 chips/hand | exact guarantee |
| Gain after 100 hands, held-out opponents (frozen RNR rule vs baseline) | +0.131 chips/hand; vs mixing +0.115 [+0.075, +0.155] | measured |
| Gain after 100 hands, out-of-population styles | +0.619; vs mixing +0.537 [+0.307, +0.766] | measured |

## Known limitations

* **No evidence against real human players.** Calibration was measured on
  simulated development opponents only.
* **Leduc only.** There is no Texas Hold'em. Exact evaluation does not
  scale there.
* **One-time hero training.** A fresh install trains the hero for about
  30 minutes. The strategy file is a generated artifact and is not in git.
* **Sessions are in memory.** They are lost when the backend restarts. There
  are no accounts and no database. The app is for a single local user on
  127.0.0.1.
* **The API address is baked into the web build.** The launcher rebuilds
  automatically when it changes.
* **A deceptive opponent costs at most the budget.** At the moment of a style
  switch the measured worst loss was 0.102 chips/hand.
* **Platforms.** The launcher uses POSIX process groups, so it supports macOS
  and Linux; it is tested on macOS only. Windows is untested.

## Possible future work (not part of v1)

* Attach the hero strategy to a GitHub release, so a fresh install can skip
  the 30-minute training. Its digest is verified on load in any case.
* Persistent sessions, for example a local SQLite store.
* A user study with real players, to measure calibration and gains on
  humans.
* Larger games with sampled (non-exact) evaluation, and the guarantees that
  would be lost.
